# Gira México 2026 · Acuarela Mimbi

Web del elenco para la gira: recorrido, vuelos, lugares, tips y qué llevar.
Se instala en el celular como app (PWA) y funciona sin internet después de abrirla una vez.

- Publicada con GitHub Pages desde la rama `main`.
- Para que los celulares reciban una versión nueva, cambiar `VERSION` en `sw.js`.
